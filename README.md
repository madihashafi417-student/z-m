# ZM Pret & Couture (ز • م) 🇵🇰

A luxury ecommerce web application tailored specifically for the Pakistani clothing market, featuring unstitched lawn, ready-to-wear pret, winter collections (Khaddar, Marina, Karandi), festive shaadi couture, bespoke Pakistani master tailoring (Darzi) customizer, nationwide Cash on Delivery (COD), and mobile wallet integration.

---

## 🌟 Key Features for the Pakistani Market

- **Dual English & Urdu Typography**: Custom styling using **Cinzel**, **Cormorant Garamond**, and **Plus Jakarta Sans** with Urdu calligraphy (`ز • م`).
- **Pakistani Currencies & Global Switcher**:
  - Pakistani Rupees (PKR `Rs.`) with localized comma formatting
  - Real-time conversion for Overseas Pakistanis: USD (`$`), GBP (`£`), and AED (`د.إ`)
- **Authentic Seasonal Collections**:
  - **Summer Luxury Lawn '26**: 3-Piece combed Pima cotton lawn with laser-cut organza borders and pure Chinese digital silk dupattas
  - **Winter Collection '26**: Heavy hand-spun Cotton Khaddar, insulating Winter Marina, Korean Micro Velvet 9000, and textured Karandi
  - **Shaadi & Festive Couture**: Pure crinkle chiffon, hand-embellished zardozi, Banarsi ghararas, and gotta kinari
  - **Men's Eastern Collection**: 100% Egyptian Giza cotton crisp latha kurta shalwar and embroidered raw silk waistcoats
  - **Heirloom Shawls**: Pure pashmina and micro velvet with Kashmiri sozni and tilla borders
- **Bespoke Master Tailoring (Darzi) Customizer**:
  - Detailed unstitched yardage breakdown (Front, Back, Sleeves, Dupatta, Trouser meterage)
  - Custom stitching options:
    - *Unstitched Fabric* (+Rs. 0)
    - *Standard Stitched* (XS, S, M, L, XL) with integrated Pakistani size chart in inches
    - *Bespoke Custom Stitching*: Enter measurements (length, chest, waist, hip, sleeves) and select authentic Pakistani bottom styles (*Traditional Shalwar, Straight Pant, Cigarette Pant, Tulip Shalwar, Flared Gharara*)
- **Nationwide Logistics & Tracking**:
  - Free delivery threshold across Pakistan on orders over Rs. 4,999
  - Major Pakistani cities supported (Karachi, Lahore, Islamabad, Rawalpindi, Faisalabad, Multan, Peshawar, Quetta, Gujranwala, Sialkot, Hyderabad, etc.)
  - Interactive **TCS Express** / **Leopards Courier** tracking modal
- **Pakistani Payment Methods**:
  - **Cash on Delivery (COD)** (Nationwide doorstep cash payment)
  - **JazzCash Mobile Wallet** with MPIN push notification
  - **Easypaisa Wallet** with OTP authorization
  - **Raast ID & Direct Bank Transfer** (0% fee instant payment to Meezan Bank / HBL: `raast@zmcouture`)
  - **Debit / Credit Card** (Visa, Mastercard, PayPak)
  - Discount voucher engine supporting codes: `EID2026`, `KHUSHAMDEED`, `ZMVIP`, `ZM2026`
- **Customer Support**:
  - Floating WhatsApp VIP Stylist Helpline (+92 300 1234567) with quick preset queries
  - Flagship store addresses in Lahore, Karachi, and Islamabad

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/madihashafi417-student/z-m.git
   cd z-m
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

### Building for Production

To create an optimized production build:
```bash
npm run build
```
